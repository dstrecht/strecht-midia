Política de privacidade: Strecht Simulados

Última atualização: 11 de outubro de 2026.

O que é o aplicativo

O aplicativo "Strecht Simulados" é uma automação de uso próprio de Diego Strecht. Ele publica, no canal do YouTube Strecht Simulados, vídeos curtos de divulgação dos simulados (questões comentadas e ofertas dos cursos na Udemy).

Dados que o aplicativo acessa

O aplicativo usa a YouTube Data API apenas com a permissão de envio de vídeos (youtube.upload) para o canal do próprio autor. Ele não lê, coleta, armazena nem compartilha dados de outros usuários do YouTube ou do Google.

O token de acesso fica guardado apenas no computador do autor e é usado somente para enviar os vídeos do canal.

Uso dos serviços do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado. Os vídeos publicados seguem os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
